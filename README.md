Netflix Data Analysis 📊

📌 Project Overview

This project focuses on analyzing Netflix content data using Python and its popular data analysis libraries.

The main objective is to clean the dataset, analyze Movies and TV Shows, identify top content-producing countries, and understand release-year trends.

This project was completed as part of a 1-month Data Analysis Internship.

🎯 Project Objectives

- Clean and preprocess the Netflix dataset.
- Analyze the distribution of Movies and TV Shows.
- Identify the top countries contributing Netflix content.
- Analyze content release trends over the years.
- Create meaningful charts and reports.
- Extract useful insights from the dataset.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- OpenPyXL
- Visual Studio Code (VS Code)

📂 Dataset Information

- Dataset Name: Netflix Titles Dataset
- Total Records: 8,790
- Total Columns: 10
- File Format: Excel (.xlsx)

The dataset contains information about Netflix movies and TV shows, including title, content type, country, release year, rating, duration, and other details.

⚙️ Installation and Setup

Step 1: Clone the Repository

git clone https://github.com/alok8009k-tech/Netflix-Data-Analysis.git

Step 2: Open the Project Folder

cd Netflix-Data-Analysis

Step 3: Install Required Libraries

pip install -r requirements.txt

Step 4: Run Python Scripts

Execute the following scripts one by one:

python task1_data_cleaning.py
python task2_content_analysis.py
python task3_country_analysis.py
python task4_trend_analysis.py

The generated reports, cleaned dataset, and visualizations are saved in the "outputs/" folder.
